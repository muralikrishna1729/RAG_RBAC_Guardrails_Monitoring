# Enterprise RBAC RAG System: Architecture & Mathematical Specifications

This document details the exact technical specifications, mathematical equations, and execution flowcharts for the **Enterprise RBAC RAG System**.

---

## 1. Mathematical Formulations

### A. Cosine Similarity (Dense Vector Search)
Given a query embedding vector $\vec{q}$ and document chunk embedding vector $\vec{d}$:

$$\text{CosineSimilarity}(\vec{q}, \vec{d}) = \frac{\vec{q} \cdot \vec{d}}{\|\vec{q}\| \|\vec{d}\|} = \frac{\sum_{i=1}^{n} q_i d_i}{\sqrt{\sum_{i=1}^{n} q_i^2} \sqrt{\sum_{i=1}^{n} d_i^2}}$$

In our system, vectors are 384-dimensional floating point arrays generated by `all-MiniLM-L6-v2`.

---

### B. Reciprocal Rank Fusion (RRF)
To merge ranked retrieval lists from **BM25 Lexical Search** ($R_{\text{bm25}}$) and **ChromaDB Dense Search** ($R_{\text{chroma}}$), we calculate the RRF score for document $d$:

$$\text{RRF\_Score}(d \in D) = \sum_{m \in \{\text{bm25}, \text{chroma}\}} \frac{1}{k + r_m(d)}$$

Where:
- $k = 60$ (smoothing constant).
- $r_m(d)$ is the 1-based rank position of document $d$ in retrieval system $m$.

---

### C. Ragas Metrics Formulations

#### 1. Context Precision
$$\text{Context Precision@K} = \frac{\sum_{v=1}^{K} (\text{Precision@v} \times v_k)}{K}$$

Where $v_k \in \{0, 1\}$ indicates whether chunk at rank $v$ is relevant to ground truth.

#### 2. Faithfulness
$$\text{Faithfulness} = \frac{|\text{Claims in Answer Grounded in Context}|}{|\text{Total Claims in Answer}|}$$

## 2. RBAC Vector Search Query Logic

When a user with role $R$ queries ChromaDB:

```python
if R == "admin":
    # Bypass security filter
    query_kwargs = {"k": 6}
else:
    # Enforce retrieval-layer security filter inside vector store engine
    query_kwargs = {
        "k": 6,
        "filter": {
            "$or": [
                {"role": R},
                {"role": "general"}
            ]
        }
    }
```

This ensures chunks belonging to other restricted departments are never read from disk or loaded into memory during vector search execution.
